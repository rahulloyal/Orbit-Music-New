Orbit Music is a beautiful, feature-rich music player designed as an open-source alternative to YouTube Music. It offers seamless music streaming, offline downloads, synchronized lyrics, and a stunning "liquid glass" UI—all without ads!

## ✨ Features

- 🚫 **No Ads**: Enjoy your music completely uninterrupted.
- 🎨 **Beautiful UI**: Experience a modern, customizable interface with "Liquid Glass" aesthetics.
- 📥 **Offline Downloads**: Save your favorite songs and playlists to listen anywhere.
- 🎤 **Synchronized Lyrics**: Sing along with dynamic, synced lyrics.
- 🔄 **In-App Updates**: Automatically fetches and updates to the latest releases via GitHub.
- 📱 **Cross-Platform Foundation**: Built with Kotlin Multiplatform and Jetpack Compose.
